## 🚀 Quick Start

### Prerequisites
- Node.js 18+ (推荐使用 [nvm](https://github.com/nvm-sh/nvm#installing-and-updating))
- npm, yarn, or bun

### 1. Clone
```bash
git clone https://github.com/Shiwam59/HH-goa.git
cd HH-goa
```

### 2. Install Dependencies
```bash
npm install
# or
bun install
```

### 3. Run Development Server
```bash
npm run dev
# or
bun dev
```

### 4. Open in Browser
Open **http://localhost:3000** 🎉

## 📁 Project Structure

```
HH-goa/
├── public/              # Static assets
├── src/
│   ├── components/      # Reusable UI components
│   ├── hooks/           # Custom React hooks
│   ├── lib/             # Utility functions
│   ├── routes/          # Page routes (TanStack Router)
│   ├── styles.css       # Global styles
│   ├── router.tsx       # Router configuration
│   └── server.ts        # Server configuration
├── index.html           # Entry HTML
├── vite.config.ts       # Vite configuration
├── tsconfig.json        # TypeScript config
├── package.json         # Dependencies
└── vercel.json          # Vercel deployment config
```

## 🎨 Customization

### Colors
Edit `src/styles.css` to change the color palette:
```css
:root {
  --background: 0 0% 100%;
  --foreground: 222.2 84% 4.9%;
  --primary: 222.2 47.4% 11.2%;
  /* ... */
}
```

### Content
- Property data: `src/components/` (property cards)
- Images: `public/` directory
- Page routes: `src/routes/`
